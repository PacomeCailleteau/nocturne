# Nocturne

Museum mysteries built with Angular. The experience starts in French; the completed game will also support English.

## Requirements

- Node.js 24.22.0, recorded in `.node-version`.
- npm 11.19.1, supplied with that Node release.
- No global Angular CLI is required.

## Development

```sh
npm ci
npm start
```

Open the local URL printed by Angular. Node must match the supported version before installing dependencies.

```sh
npm run build
npm test -- --watch=false
```

## Current architecture

This initial foundation uses Angular 22.2.3, standalone components and strict TypeScript. The repository is separate from course material and private preparation documents.

## AI assistance

Codex assisted with requirements analysis, technical planning and project setup. Angular CLI generated the initial framework configuration. Implementation, validation results and remaining limitations will be recorded here as the game is completed.
